UNA MIRADA SOBRE EL IDIOMA

El español no se aprende solamente. Se vive.

El español no existe aislado de las personas que lo hablan. Tiene acentos, historias, gestos, humor, costumbres y diferentes maneras de entender el mundo.

Por eso, este espacio nace para unir dos cosas que forman parte de mi vida: la enseñanza del español y el encuentro entre culturas.

Desde Estambul, con una mirada argentina, quiero compartir una forma de aprender español más cercana, real y humana.

Profesora.
Argentina.
Viajera.

Soy Belén, profesora de español con 22 años de experiencia enseñando idiomas. Actualmente formo parte del Instituto Cervantes y soy examinadora DELE de A1 a C2.

Trabajo con estudiantes de distintos países y niveles, combinando comunicación, cultura y situaciones reales para que el español no se quede dentro de un libro.
