# Una Argenta en Estambul - Landing

Primera versión estática de la landing page.

## Archivos
- index.html: estructura y contenido
- style.css: diseño, colores, tipografías y responsive
- script.js: menú móvil, header al hacer scroll y año del footer
- images/: carpeta reservada para fotografías reales

## Para personalizar
1. Reemplazar los bloques "TU FOTO" / "FOTO" por las fotografías reales.
2. Cambiar los enlaces `href="#"` por Instagram, Preply, LinkedIn y WhatsApp.
3. Ajustar los textos de servicios y presentación.
4. Cuando el contenido esté aprobado, conectar el dominio `argenta.tr` con Netlify.

## Paleta inicial
- Azul noche: #071820
- Azul profundo: #0B222C
- Dorado: #C99B55
- Dorado claro: #E4BD7D
- Crema: #EEE3D0

La estructura está pensada para crecer después con blog, testimonios, recursos, DELE, cultura Argentina-Turquía, etc.
